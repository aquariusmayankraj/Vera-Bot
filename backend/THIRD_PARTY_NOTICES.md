# Attribution and scope

`challenge_reference/` contains the user's supplied magicpin Vera challenge
materials unchanged. Attribution and rights in those materials remain with their
respective authors. `expanded/` and the 30 canonical preview rows are generated
from that supplied synthetic dataset. No ownership of the challenge material or
official endorsement is claimed.

The application source and tests in this package were prepared as AI-assisted
implementation for the requesting user. Review, understand and customize the
implementation before submitting it. Follow the challenge's actual rules on
assistance, disclosure, eligibility and authorship; do not claim work or credentials
that are not yours.

Python, FastAPI, Pydantic, Uvicorn and the other dependencies have their own licenses.
Install them from their normal distributions. No provider API key, private customer
database, real WhatsApp template approval or cloud account is included.
